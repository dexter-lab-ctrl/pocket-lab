# Pocket Lab Documentation

Pocket Lab is an edge-first, self-hosted control-plane and lab orchestration platform.

It provides:

- React/Vite PWA operator interface
- FastAPI control plane
- NATS / JetStream command and event bus
- Worker-based typed operation execution
- Event-sourced workflow engine
- App Catalog and Blueprint deployment
- Mesh Fleet and edge node management
- Health, telemetry, release, drift, backup, and security workflows
