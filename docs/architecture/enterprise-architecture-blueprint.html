2. System Blueprint

Pocket Lab is an edge-first self-hosted control plane. The frontend is a React/Vite PWA. The backend is a FastAPI API that publishes typed commands to NATS/JetStream. Workers consume those commands, execute typed operations, publish lifecycle events, and feed an event-sourced workflow engine. The browser receives live events through WebSocket with polling fallback.

Frontend contract

The PWA sends only typed operation payloads and stable FastAPI-owned URLs. It rejects HTML fallback responses, normalizes degraded payloads, and keeps panels isolated with error boundaries.

Backend contract

FastAPI owns all browser-facing API contracts. It requires NATS/JetStream for write operations and returns 503/403 rather than silently executing locally when the control plane is unavailable.

Event contract

Commands, events, audit records, telemetry, and DLQ messages are first-class subjects. Recent event replay and WebSockets allow the UI to remain live even through reconnects.

Write request arrives
  → authenticate request
  → check worker execution policy
  → if direct/in-process mode requested without explicit allowance: 403 forbidden
  → if NATS/JetStream unavailable: 503 unavailable
  → else create queued run / domain command

9. Security, Reliability, and Resilience Blueprint

Fail-closed writes

Write actions require NATS/JetStream and worker-owned execution. When unavailable, FastAPI returns structured 503/403 responses and the UI shows degraded control-plane state instead of using unsafe fallback execution.

Auth boundaries

Writes call require_auth(write=True). Bearer tokens and x-pocket-lab-token are supported. Loopback/local-write behavior is controlled by runtime policy rather than hardcoded trust.

Event durability

JetStream streams separate commands, events, audit, telemetry, and DLQ subjects. Reliability services support retry, dead-letter inspection, replay, and recovery.

UI crash containment

Error boundaries, defensive JSON parsing, normalized health payloads, and fail-soft catalog/blueprint handling prevent blank-screen failures from malformed backend data.

Secrets and policy

Identity Vault surfaces safe access workflows. Policy Guardrails and Security Posture expose OPA/security evidence while avoiding root material exposure in the UI.

Degraded operations

Fault gates validated NATS down, worker down, Vault sealed, bad health payloads, low disk telemetry, stale fleet agents, drift, release failure, and WebSocket fallback.

10. How Operators Use Pocket Lab

Install or update an app/service

  1. Open App Catalog or Simple Mode Apps & Services.
  2. Click Refresh catalog / Check for New Apps to submit a typed catalog refresh.
  3. Choose source mode/reference if needed.
  4. Click Deploy Workload / Install.
  5. Watch live progress in the event panel; open Advanced Details for operation IDs and technical payloads.

Run a release update

  1. Open Release Workflow or Simple Mode Updates.
  2. Click Check release to discover current vs target release.
  3. Click Apply latest to run release orchestration.
  4. Monitor stages: prepare, sync, deploy, verify, catalog refresh, health verification, PWA refresh readiness.

Add or manage edge devices

  1. Open Mesh Fleet or Simple Mode My Devices.
  2. Review online/offline/stale agents.
  3. Create device invite/bootstrap or send node/broadcast commands.
  4. Use NOC Telemetry/System Status to watch fleet and device health.

Investigate issues

  1. Open Drift Center / Health & Issues for drift or state mismatch.
  2. Open NOC Telemetry / System Status for CPU, memory, disk, temperature, and live status.
  3. Open Security Posture / Safety Center for policy/security status.
  4. Open Log Explorer for event/log context.

Recover safely

  1. Open Disaster Recovery / Backups.
  2. Run Backup Now before risky changes.
  3. Use Verify Backup before restore.
  4. Use Restore only with the intended backup reference and watch event progress.
